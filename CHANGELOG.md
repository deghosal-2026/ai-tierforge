All notable changes to ai-tierforge will be documented in this file.

## [0.1.0] — 2026-07-17

### Added
- Initial release
- Multi-model tier router (architect, workhorse, utility)
- Cost-per-completed-task accounting with retry and escalation tracking
- Escalation rate SLO monitoring and threshold alerts
- OMLX local LLM integration as first-class utility tier
- CLI interface with cost reporting
- Cost showback by team and project
